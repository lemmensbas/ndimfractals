The idea

An iterated function system (IFS) is a family of contracting maps. Its invariant set K is the set that equals the union of its own images under all the maps. It is self-similar: each piece is a shrunken, distorted copy of the whole.

Here the maps are inversions. Inversion in the unit sphere sends x to x/‖x‖², so a point at distance r from the origin goes to distance 1/r on the same ray. Composing it with a lattice translation gives, for each b in ℕ×ℤd−1, the map

θb(x) = (x + b) / ‖x + b‖², x ∈ B = open ball of radius ½ centred at (½, 0, …, 0)

The alphabet is infinite: b = (n, m) in the plane with n ≥ 1, b = (n, m, k) in 3-space, b = (n, m, k, l) in 4-space. Each such map is conformal: it preserves angles and acts on small pieces as a similarity with ratio 1/‖x + b‖². In dimension 3 and up, Liouville’s theorem says that conformal maps are Möbius transformations, so inversions are essentially the only maps of this kind.

A sign convention: the page uses x + b, which keeps everything inside the ball. With x − b exactly as first written, the same construction works in the mirror-image ball centred at (−½, 0, …, 0), and the picture is reflected.

Why it works

The ball is the right domain. A point x lies in B exactly when ‖x‖² < x1. Inversion swaps B with the half-space {y1 > 1}. For x in B, the first coordinate of x + b exceeds n ≥ 1, so θb(x) lands back in B. Each map sends B into itself.

The pieces tile without overlap. The translated ball B + b is a ball of radius ½ centred at b + (½, 0, …), and neighbouring lattice translates touch at single points. Inversion maps balls to balls, so θb(B) are disjoint open balls that touch their neighbours. This is the picture you see in the 2D demo with “first-level pieces” switched on, and it is the open set condition from fractal geometry.

Contraction. The derivative of θb has norm 1/‖x + b‖², which is below 1 on B but approaches 1 near the corner x = 0 for b = (1, 0, …). So, as with ordinary continued fractions, the system is not uniformly contracting at the first step, and one works with composed maps. The theory of infinite conformal IFS (Mauldin and Urbański) covers this setting.

Dimension. The pieces have size about ‖b‖−2, and the sum Σb ‖b‖−2t over a d-dimensional lattice converges exactly when t > d/2. This number d/2 is the system’s finiteness parameter, and a standard result says the Hausdorff dimension of the limit set is at least that. It gives a lower bound only; I have not computed the actual dimension.

The link to continued fractions

On the real line, the maps x ↦ 1/(x + n) with n = 1, 2, 3, … generate the classical continued fractions 1/(n₁ + 1/(n₂ + 1/(n₃ + …))). Their images cover [0, 1], apart from the endpoint 0 which is only a limit, and every number there has such an expansion. The Gauss map is the inverse dynamics.

In the plane, identify points with complex numbers. Inversion x/‖x‖² becomes z ↦ 1/z̄, so

θb(z) = 1 / conj(z + b), b = n + im, n ≥ 1

Composing two consecutive maps cancels the two conjugations and gives holomorphic Möbius maps. The limit set is therefore a set of continued-fraction-type expansions with digits in the Gaussian integers with positive real part, in the spirit of Hurwitz-style complex continued fractions. In higher dimensions the same construction works with Möbius transformations of ℝd, which no longer have a complex-number description.

Live 2D demo

This runs in your browser using the chaos game: start at any point, repeatedly apply a randomly chosen θb, and plot where you land. Because the maps contract, the orbit settles onto K and then wanders over it. Digits are weighted by ‖b‖−3 so the large pieces fill in quickly.

With “first-level pieces” on, you see the discs θb(B) for |b| ≤ about 3. Each is an inverted copy of B; they touch one another and cover the set except for a thin boundary. Large digits produce tiny discs that crowd toward the point 0 on the left and toward its images, which is where the dense clusters of dots form.

3D and 4D

The same formula works in any dimension. In ℝ³ the invariant set is a cloud, and in ℝ⁴ it lives in a 4-dimensional ball. To look at it we need slices.

What a slice shows. A planar slice of the 3D set is a section of a set of dimension at least 3/2 by a 2-dimensional plane, so it can look quite different from the planar fractal above. For the plane x₃ = 0 it contains the 2D set, because the digits with k = 0 preserve that plane. Other planes, such as x₁ = ½ or x₂ = x₃, meet only some of the pieces, which gives sparse trees and isolated clusters.

Rotating a hyperplane in 4D. The 4D animation rotates the whole point cloud by a 4×4 rotation matrix and keeps only points within a thin slab around the fixed hyperplane w = 0. Equivalently, the cutting hyperplane turns through 4D. A rotation in the xi–x₄ plane tilts the hyperplane toward the xi direction, which is why points seem to appear, merge and vanish as the slice passes through them.

Notes on what the pictures are

All pictures are samples of the set, not exact drawings. Three approximations matter:

  • Truncated alphabet. The alphabet is infinite, but each picture uses only digits up to some bound. The smallest pieces, near the accumulation point 0, are cut off or sparsely sampled.
  • Weighted random choice. The weights decide how dense each region looks, not which points belong to the set.
  • Finite thickness of slices. A slice is a thin slab of points, so it also catches a small neighbourhood on either side.

For further reading, look up conformal iterated function systems and limit sets of infinite conformal IFS (Mauldin–Urbański), complex continued fractions (Hurwitz, Hensley), and Möbius transformations in higher dimensions.
